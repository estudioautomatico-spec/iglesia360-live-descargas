# Iglesia360 Live — descargas

Este repositorio **no contiene código**: solo publica las versiones de
Iglesia360 Live para macOS como Releases.

- **Instalar a mano:** abrí [Releases](https://github.com/estudioautomatico-spec/iglesia360-live-descargas/releases/latest),
  bajá `Iglesia360-Live_X.Y.Z_universal.dmg` y seguí la guía
  "Cómo abrir la primera vez" que viene dentro del `.dmg`.
- **Actualizar:** desde la app, en Ajustes → Actualizaciones → "Actualizar ahora".
  La app verifica la firma del paquete y la identidad de código antes de
  instalar nada.

Cada Release trae el `.dmg` (instalación manual) y el `.app.tar.gz`
(actualización desde la app).
